## Overview

This repository includes several homework assignments that focus on implementing and understanding various machine learning algorithms and techniques. Each assignment explores a different concept, providing hands-on experience with real-world data.

## Project Structure

The repository is organized into the following directories:

- `HW1-Regression/` - Implementation of regression techniques.
- `HW2-CentroidClassifier-BayesClassifier/` - Exploration of centroid and Bayesian classifiers.
- `HW3-GMM/` - Implementation of Gaussian Mixture Models.
- `HW4-KNN/` - Application of the K-Nearest Neighbors algorithm.
- `HW5-PCA/` - Exploration of Principal Component Analysis.

## HW1 - Regression

**Objective**: This assignment focuses on implementing regression techniques to model and predict continuous data. Various regression models, including linear regression with regularization, are explored to understand their behavior and performance.

**Key Components**:
- **Bias-Variance Tradeoff**: Analyze the effect of the regularization parameter on the bias and variance of the model.
- **Gradient Descent**: Implement gradient descent for optimizing the regression model.
- **Simulation**: Use the dataset provided to perform simulations and validate the model’s performance.

## HW2 - Centroid Classifier & Bayes Classifier

**Objective**: This assignment involves implementing and comparing the Centroid Classifier and Bayesian Classifier on different datasets. The aim is to understand the underlying assumptions and effectiveness of each classifier in different scenarios.

**Key Components**:
- **Centroid Classifier**: Implementation and evaluation on given datasets.
- **Bayesian Classifier**: Derive and implement the Bayes classifier, and compare its performance with the Centroid Classifier.
- **Feature Selection**: Apply feature selection techniques to improve the classifiers' performance.

## HW3 - Gaussian Mixture Models (GMM)

**Objective**: This assignment explores the use of Gaussian Mixture Models for clustering and density estimation. GMMs are probabilistic models that assume all data points are generated from a mixture of several Gaussian distributions.

**Key Components**:
- **Implementation**: Implement the GMM algorithm for clustering.
- **Clustering**: Apply GMM to datasets to perform clustering and analyze the results.
- **Evaluation**: Evaluate the performance of GMM using appropriate metrics.

## HW4 - K-Nearest Neighbors (KNN)

**Objective**: The KNN algorithm is a simple, non-parametric method used for classification and regression. This assignment involves implementing the KNN algorithm and applying it to various datasets to explore its effectiveness.

**Key Components**:
- **Implementation**: Implement the KNN algorithm for classification tasks.
- **Overfitting and Underfitting**: Analyze the impact of the number of neighbors \(k\) on overfitting and underfitting.
- **Curse of Dimensionality**: Study the impact of high-dimensional data on the performance of KNN.

## HW5 - Principal Component Analysis (PCA)

**Objective**: PCA is a dimensionality reduction technique used to reduce the number of variables in a dataset while preserving as much information as possible. This assignment focuses on implementing PCA and applying it to datasets to reduce dimensionality.

**Key Components**:
- **Implementation**: Implement PCA to reduce the dimensionality of the given datasets.
- **Eigenfaces**: Use PCA to perform facial recognition by reducing the dimensionality of facial image data.
- **Explained Variance**: Analyze the variance explained by the principal components and its impact on data representation.
